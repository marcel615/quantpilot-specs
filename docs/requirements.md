## 기능 요구사항

### 미국 주식·ETF 일봉 수집과 정제

- **ID:** QP-5
- **목적:** 개인 비상업 연구에서 같은 가격 입력으로 백테스트를 재현할 수 있도록 미국 주식·ETF 일봉을 수집하고 검증한다.
- **첫 검증 범위:** Alpaca Basic의 IEX 피드로 NVDA 및 SPY의 2024년 USD 일봉을 검증한다. [QP-2 금융 데이터 수집 기반 구축](https://marcel615.atlassian.net/browse/QP-2)에서 [분석 명세](analytics-spec.md)의 수집·정제·산출물 기준을 적용한다.
- **수익률 기준:** 전략과 벤치마크는 배당을 제외한 주가 수익률로 비교한다. 거래 체결을 재현할 때는 원가격을 사용하고, 주가 수익률을 비교할 때는 주식 분할만 조정한 가격을 사용한다.
- **완료 조건:** 정해진 거래일 범위에서 원가격과 분할조정 가격을 모두 수집한다. 정상 입력은 동일한 정제 결과를 만들고, 결측·충돌 중복·유효하지 않은 가격 또는 공급원 응답 실패가 생기면 실패 사유를 남기고 직전 정상 산출물을 보존한다.
- **사용 범위:** 공급원 이용 조건에서 허용하는 범위에서 개인 환경에 저장한다. 공개 데모에서 실제 시세를 표시할 경우 해당 공급원의 이용 조건을 따르는 공식 임베드 위젯을 사용한다.
