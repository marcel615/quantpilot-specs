# 분석 명세

## 목적과 적용 범위

- [QP-5](https://marcel615.atlassian.net/browse/QP-5)는 첫 가격 데이터의 수집·정제 계약이다. [QP-2](https://marcel615.atlassian.net/browse/QP-2)는 이 기준으로 개인 연구용 입력을 수집하고 검증한다.
- 최초 수집은 미국 주식과 ETF의 USD 일봉으로 한다. 전략과 벤치마크의 주가 수익률 비교 및 이후 체결 재현에 필요한 가격을 제공한다. 실제 주문 제출과 백테스트 엔진 구현은 이 명세의 범위 밖이다.

## 입력 데이터

| 항목 | 기준 |
| --- | --- |
| 공급원 | Alpaca Basic의 미국 주식 과거 일봉 API. Paper Only 계정은 공식 문서가 명시한 `iex` 피드를 사용한다. |
| 첫 수용 검증 | 미국 주식 NVDA, ETF SPY. 요청 기간은 2024-01-01부터 2024-12-31까지이며 양 끝 날짜를 포함한다. |
| 일봉과 기준일 | `1Day` 일봉. 공급원 시각을 `America/New_York`으로 환산해 거래일을 구한다. 기대 거래일은 같은 요청 기간의 Alpaca 미국 주식 거래일 달력으로 정한다. |
| 가격과 거래량 | `raw`와 `split` 요청에서 각각 시가·고가·저가·종가(USD/주)와 거래량(주)을 받는다. `split`의 가격과 거래량은 공급원의 분할조정 값이다. |

같은 요청에서 피드, 종목, 기간, 주기 및 종목 매핑 기준을 기록한다. 페이지 토큰이 있는 동안 모든 페이지를 읽고, `raw`와 `split`에는 동일한 조회 조건을 사용한다. 기대 거래일 달력의 수집 실패 또는 요청 범위에 거래일이 없는 경우에는 성공 산출물을 발행하지 않는다. [Alpaca 일봉 API](https://docs.alpaca.markets/us/reference/stockbarsingle-1) · [거래일 API](https://docs.alpaca.markets/us/v1.1/reference/getcalendar-1) · [Paper 계정 피드 조건](https://docs.alpaca.markets/us/docs/paper-trading)

## 처리와 계산 규칙

- 각 조정 모드에서 고유 키는 `symbol`과 `trade_date`의 조합이다. 같은 키와 동일한 시가·고가·저가·종가·거래량은 한 행으로 합친다. 같은 키에서 이 값 중 하나라도 다르면 유효한 행을 임의로 고르지 않고 전체 요청을 실패 처리한다.
- 두 조정 모드를 키로 결합한다. 요청 종목별로 두 모드 모두 기대 거래일마다 한 행이 있어야 한다. 기대 거래일이나 필수 값이 빠지거나, 요청 밖 날짜 또는 종목이 반환되거나, 조회가 완결되지 않으면 실패 처리한다. 결측값을 앞선 값이나 0으로 채우지 않는다.
- 두 모드에서 가격은 유한한 양수이고 거래량은 유한한 0 이상의 값이어야 한다. 저가는 시가·종가 이하여야 하고 고가는 시가·종가 이상이어야 한다. 가격 변동 폭이나 배당락만을 이유로 정상 가격을 삭제하거나 보정하지 않는다.
- 거래 체결의 가격을 재현할 때 원가격을 사용한다. 가격 시계열의 연속성과 수익률 비교를 위해 주식 분할만 조정한 종가를 사용한다. 기간 주가 수익률은 마지막 거래일의 분할조정 종가를 시작 거래일의 분할조정 종가로 나눈 뒤 1을 뺀 값이다. 전략과 벤치마크는 같은 가격 기준과 비교 기간을 사용한다. 배당 현금 흐름, 배당조정 가격, 배당 재투자 및 총수익률은 첫 버전의 계산에서 제외한다.
- 한 건이라도 실패하면 종목·거래일·조정 모드와 실패 이유를 확인 가능한 범위에서 기록한다. 두 조정 모드 및 모든 종목의 검증이 끝난 뒤에만 해당 요청의 정상 결과를 교체한다. API 오류나 중간 단계 실패가 발생하면 부분 결과를 정상 결과로 사용하지 않고 직전 정상 결과를 보존한다.

## 산출물과 지표

- UTF-8 CSV에서 종목과 거래일 오름차순으로 정렬한다. 헤더는 `symbol,trade_date,currency,open_raw,high_raw,low_raw,close_raw,volume_raw,open_split,high_split,low_split,close_split,volume_split` 순서이며, 날짜는 `YYYY-MM-DD`, 통화는 `USD`다.
- 재현 기록에는 공급원, 피드, 종목, 요청 기간, 주기, 통화, 종목 매핑 기준, 두 조정 모드, 수집 시각과 결과 행 수를 담는다. 같은 응답과 설정을 다시 처리하면 정제 CSV의 행 수·정렬·값이 일치해야 한다. 수집 시각과 같은 실행 기록은 재처리마다 갱신할 수 있다.
- 원천 응답, 정제 CSV 및 재현 기록의 기본 저장 경로는 Analytics 저장소 루트 기준 `.local/market-data/`다. Analytics의 Git 무시 목록에 `/.local/`을 추가하고 해당 폴더를 배포 산출물에서 제외한다.
- 실제 가격 파일의 지속 저장은 계정에 적용되는 이용 조건에서 허용 범위와 보존 기간을 확인한 후, 접근 권한이 본인으로 제한된 개인 환경에서 한다. 확인 전에는 응답을 저장하지 않고 실행 중에 검증한다. 합성 데이터로 파일 저장과 실패 복구를 검증할 수 있다.
- 실제 가격 자료와 인증 정보는 공개 저장소나 공개 페이지에 싣지 않는다. 공개 데모에서 실제 시세를 표시할 때는 별도의 공식 임베드 위젯을 사용한다. [Alpaca 이용 조건 및 공시](https://alpaca.markets/disclosures)

## 수용 기준

- **정상 수집:** 2024년 IEX 표본에서 NVDA와 SPY는 각각 2024-01-02부터 2024-12-31까지 252개 거래일과 일치한다. 각 조정 모드가 같은 키를 제공하고 결합 후 CSV에는 504행이 있어야 한다.
- **분할:** NVDA 2024-06-07의 원종가를 분할조정 종가로 나눈 비율은 표시 정밀도를 감안해 9.999 이상 10.001 이하다. 분할조정 거래량은 원거래량의 10배다. 2024-06-10의 원종가와 분할조정 종가, 원거래량과 분할조정 거래량은 각각 같다. [NVIDIA 분할 공시](https://investor.nvidia.com/files/doc_downloads/2024/06/nvidia-2024-stock-split_faq_investors.pdf)
- **배당 제외:** 합성 표본의 분할조정 종가가 100에서 99로 바뀌고 별도로 주당 배당 1이 주어져도 주가 수익률은 -1%다. SPY의 배당락 전후 가격 행 역시 다른 품질 규칙을 충족하면 보존한다.
- **동일 재처리와 중복:** 같은 응답 및 설정을 두 번 처리해 CSV 행 수·정렬·값이 일치하는지 확인한다. 같은 가격·거래량의 행을 추가해도 성공 결과에 키가 한 번만 나와야 한다.
- **로컬 저장:** 합성 입력을 사용해 원천 응답·정제 CSV·재현 기록이 Analytics 루트의 `.local/market-data/` 아래에 생성되는지 확인한다. Git과 배포 산출물에서 해당 폴더가 제외되어야 한다.
- **실패:** 거래일 한 건 누락, 같은 키의 값 충돌, 필수 가격 누락 또는 0 이하 가격, 가격 범위 위반, 두 번째 페이지 조회 실패를 각각 재현한다. 모든 경우 실패 사유가 남고 앞서 성공한 결과가 보존돼야 한다.

## 미결 사항

- 개인 계정에 적용되는 원천·정제 데이터의 저장 권한 및 보존 기간을 확인한 뒤 실제 가격 파일의 로컬 저장을 사용한다. 구현에서 합성 데이터로 검증할 수 있는 범위와 실제 저장 검증 결과를 구분한다.

## 첫 일봉 기반 수익률 예측 실험

[QP-9](https://marcel615.atlassian.net/browse/QP-9)는 [QP-8](https://marcel615.atlassian.net/browse/QP-8)의 첫 오프라인 실험 기준이다. 위 수집·정제 계약에 따라 검증한 NVDA·SPY의 2024년 USD 일봉(2024-01-01부터 2024-12-31까지)을 사용한다. 거래일은 뉴욕 기준 달력으로 정한다. 각 행은 한 종목의 한 기준 거래일 `t`다.

### 예측 목표와 입력

- 거래일 `t`의 장 마감에 다음 거래일의 배당 제외 주가 수익률을 예측한다. 정답은 같은 종목의 `close_split[t+1] / close_split[t] - 1`이다. `t+1`은 달력상 다음 거래일이다.
- 입력은 기준일 장 마감까지의 일봉으로 계산한다. 모든 수익률과 거래량은 종목별로 계산한다.

| 입력 | 계산 |
| --- | --- |
| 최근 1·5·20거래일 수익률 | 각 기간 `n`에 대해 `close_split[t] / close_split[t-n] - 1` |
| 20거래일 변동성 | 기준일을 포함한 최근 20개의 일간 수익률의 표본 표준편차. 연율화 없이 수익률과 같은 단위로 기록한다. |
| 상대 거래량 | `volume_split[t]`를 기준일을 제외한 직전 20거래일의 `volume_split` 평균으로 나눈 값 |

입력 계산에 필요한 일봉이 부족하거나 상대 거래량의 분모가 0이면 해당 행을 제외하고 사유와 건수를 기록한다. 결측값을 채우거나 누락된 거래일을 건너뛰어 계산하지 않는다. 정제 입력 자체가 수집 품질 기준을 위반하면 해당 실험 입력을 거부한다. 검증과 최종 평가의 특징값을 만들 때는 기준일 전에 확보한 이전 구간의 가격 이력을 사용할 수 있다.

### 시간순 학습과 평가

| 기준 거래일 | 용도 |
| --- | --- |
| 2024년 1–9월 | 전처리 적합 및 리지 회귀 후보 학습 |
| 2024년 10월 | 리지 회귀 설정 선택 |
| 2024년 11–12월 | 선택한 모델과 0% 기준선의 최종 평가 |

- 같은 기준 거래일의 두 종목을 같은 구간에 둔다. 다음 거래일이 다른 구간에 속하거나 정답이 없으면 해당 행을 평가·학습 표본에서 제외한다.
- 전처리 설정은 학습 구간에서만 적합한다. 실험 시작 전에 후보 설정과 동점 처리 규칙을 기록하고, 10월 MAE로 설정을 선택한다. 선택한 1–9월 학습 모델 및 전처리를 그대로 11–12월의 최종 평가에 사용한다. 최종 평가 자료를 후보 설정 선택이나 재학습에 사용하지 않는다.
- 0% 기준선과 리지 회귀는 같은 유효 행에서 비교한다. MAE는 예측값과 실제 수익률 사이의 절대오차 평균이다. 평가 기간, 두 모델의 MAE, 오차 차이 및 평가 행 수를 기록한다. 평가 가능한 행이 0건이면 평가 실패로 기록한다.

### 재현 기록과 수용 기준

- 입력 식별 정보, 실행 명령, 환경·설정과 시간순 구간, 제외 사유별 건수, 모델·전처리 버전 및 평가 결과를 기록한다. 동일한 입력·환경·설정으로 예측값과 MAE를 재현하고, 저장한 모델과 전처리로 새 기준일의 입력에서 예측할 수 있음을 검증한다.
- 합성 입력으로 다음 거래일 목표값, 분할조정 수익률과 다섯 입력의 계산, 20거래일 이력 부족, 거래량 분모 0, 구간 경계 및 마지막 거래일의 정답 부재를 검증한다. 기준일 이후의 입력을 바꿔도 그날 특징값이 바뀌지 않아야 한다. 손계산 가능한 예측으로 MAE를 확인한다.
- 실제 2024년 표본에서 학습·검증·최종 평가를 실행하고 두 모델의 결과를 기록한다. 기준선 대비 개선은 실험 결과이며, 재현성과 누출 방지 기준을 충족하면 오차가 개선되지 않아도 실험을 완료한다.
- 실제 원천·정제 가격 파일의 지속 저장은 기존 이용 조건을 따른다. 보관 조건을 확인하기 전에는 가격 파일을 저장하지 않고 실행 중에 검증한다. 파일 저장 경로의 검증에는 합성 데이터를 사용한다.

## 보유 희망 종목 한 개의 하락 방어 후보 비교

[QP-10](https://marcel615.atlassian.net/browse/QP-10)은 [QP-1](https://marcel615.atlassian.net/browse/QP-1)의 첫 오프라인 비교 기준이다.

### 입력과 비교 기간

- NVDA와 성격이 다른 후보 최대 10개의 USD 일봉을 사용한다. QP-5의 수집·정제 기준을 적용하고 분할조정 종가인 `close_split`으로 배당 제외 주가 수익률을 계산한다. 거래일은 뉴욕 기준 미국 주식 거래일 달력의 날짜순으로 정렬한다.
- 후보 선정은 2016년부터 2025년 말까지를 우선 검토한다. 시작일은 NVDA와 입력 후보 전체에서 품질을 확인한 공통 일봉 범위에 맞춘다. 공통 범위 안에 누락된 거래일이 있으면 해당 입력을 사용할 수 없는 이유를 기록한다. 누락값은 채우지 않으며 누락 전후 종가를 연결해 수익률을 계산하지 않는다.
- 검증에는 2026년 첫 거래일부터 기록된 검증 종료 거래일까지의 공통 거래일을 사용한다. 후보군과 비교 조건, 급락 경계는 검증 성과를 보기 전에 고정한다. 고정된 후보의 검증 일봉이 불완전하면 사유와 기간을 기록하고 해당 입력으로 공식 비교를 완료하지 않는다.
- 일간 수익률은 해당 거래일의 종가를 달력상 직전 거래일 종가로 나눈 뒤 1을 뺀다. 선정 기간에서는 기간 안에서 두 종가를 확보한 날을 사용한다. 검증 첫날에는 직전 거래일인 2025년 마지막 거래일의 종가를 사용한다.

### 후보 선정과 조합 수익률

- 선정 기간의 마지막 종가를 첫 종가로 나눈 뒤 1을 뺀 누적 주가 수익률이 0% 이상인 후보를 선정한다. 후보 자체의 누적 수익률과 최대 낙폭을 표시하고, 선정 종료 전 최근 3년의 수익률과 최대 낙폭도 함께 표시한다. 최근 3년 수익률이 음수라도 전체 선정 기간 기준을 통과하면 음수임을 표시하고 비교에 포함한다. 해당 3년의 입력이 불완전하면 지표에 데이터 부족을 표시한다.
- 선정 기간 NVDA의 유효 일간 수익률 `n`개를 오름차순으로 정렬하고, 1부터 세어 `ceil(0.10 × n)`번째 관측값을 급락 경계로 사용한다. 유효한 수익률이 없으면 경계를 산출할 수 없음을 기록한다. 경계 이하이면서 음수인 NVDA 수익률을 급락일로 집계한다. 경계와 같은 음수 관측값은 모두 포함한다. 2026년 검증에는 선정 기간에서 정한 동일 경계를 적용한다.
- 매 거래일 시작에 목표 비중을 적용한다. 현금의 일수익률과 거래 비용은 0이다. NVDA와 후보의 일수익률을 각각 `r_NVDA`, `r_후보`라고 하면 세 조합의 일수익률은 다음과 같다.

| 조합 | 일수익률 |
| --- | --- |
| NVDA 100% | `r_NVDA` |
| NVDA 80%·가상 현금 20% | `0.8 × r_NVDA` |
| NVDA 80%·후보 20% | `0.8 × r_NVDA + 0.2 × r_후보` |

### 결과와 수용 기준

- 동일 거래일에서 모든 조합을 비교한다. 선정 기간과 검증 기간별로 급락일 수와 각 조합의 급락일 평균 수익률, 후보 조합에서 현금 조합을 뺀 급락일 평균 수익률 차이(%p)를 기록한다. NVDA 일수익률이 양수인 거래일의 조합별 평균 수익률도 기록한다. 해당 거래일이 없으면 평균은 산출 불가로 표시한다.
- 조합의 기간 성과는 기간 시작 직전 기준값 1에 각 일수익률의 `1 + 수익률`을 순서대로 곱해 계산한다. 마지막 값에서 1을 빼 누적 수익률을 얻는다. 각 거래일에 그날까지의 최고 누적 가치(시작 기준값 포함) 대비 하락률을 계산한다. 최대 낙폭은 이 하락률의 최댓값이며 하락률은 1에서 해당 거래일 누적 가치를 최고 누적 가치로 나눈 값을 빼서 구한다. 후보 자체의 최대 낙폭은 해당 기간 분할조정 종가의 최고점 대비 같은 방식으로 계산한다.
- 검증 급락일이 10일 미만이면 표본 부족으로 표시하고 추가 방어 효과를 판정하지 않는다. 급락일이 10일 이상이고 현금 대비 평균 수익률 차이가 양수인 후보의 추가 방어 효과를 확인한다. 선정 기준을 통과한 후보가 없거나 충분한 검증 표본에서 현금보다 나은 후보가 없으면 적합 후보 없음과 그 이유를 표시한다. 입력 품질 때문에 비교를 끝내지 못한 경우에는 그 사유를 기록한다.
- 실행 기록에는 후보 티커, 공통 시작일, 선정 및 검증 기간과 검증 종료 거래일, 입력 일봉 식별 정보, 비중과 가정, 급락 경계와 표본 수, 후보별 제외 사유를 남긴다. 동일 입력과 설정에서 후보 통과 여부와 비교 지표를 재현한다. 실제 가격의 저장은 QP-5의 데이터 이용 조건을 따른다.
- 합성 예제에서 NVDA가 −10%, 후보가 +5%인 급락일의 세 조합은 각각 −10%, −8%, −7%이며, 후보 조합은 현금 조합보다 1%p 높다. 합성 입력으로 거래일 누락, 급락 경계 동률, 9일과 10일의 표본 경계, 현금 대비 차이가 0인 경우, 최근 3년 수익률이 음수인 통과 후보를 검증한다. 검증 기간 가격을 바꿔도 선정 후보와 급락 경계가 바뀌지 않아야 한다. 명세 병합 뒤 품질을 확인한 실제 일봉으로 공식 수용 검증을 수행한다.

## 여러 보유 희망 종목의 하락 방어 후보 비교

[QP-12](https://marcel615.atlassian.net/browse/QP-12)는 [QP-11](https://marcel615.atlassian.net/browse/QP-11)의 다종목 오프라인 비교 기준이다.

### 입력과 기준 포트폴리오

- 기준 포트폴리오는 서로 다른 미국 주식·ETF 두세 종목으로 구성한다. 각 목표 비중은 양수이며 합계는 100%다. 후보는 기준 종목과 겹치지 않는 미국 ETF를 최대 10개까지 지정한다.
- QP-5의 USD 분할조정 종가, 뉴욕 거래일과 가격 검증을 적용한다. 선정 기간은 2016년 이후 품질을 확인한 공통 시작일부터 2025년 마지막 거래일까지이며, 검증 기간은 2026년 첫 거래일부터 지정한 완료 거래일까지다. 기준 종목과 선정 후보의 일봉은 두 기간의 비교에 필요한 모든 거래일에 확보한다. QP-10의 공통 시작일·후보 제외·검증 첫날 및 결측 처리 규칙을 적용한다.
- 기준 포트폴리오의 일간 수익률은 각 종목의 일간 주가 수익률과 목표 비중을 곱한 값의 합이다. 매 거래일 시작에 목표 비중을 적용한다. 선정 기간의 기준 포트폴리오 수익률로 QP-10의 하위 10% 급락 경계를 계산해 검증 기간에 고정한다. 기준 포트폴리오의 수익률이 경계 이하이면서 음수인 날을 급락일로, 양수인 날을 상승일로 집계한다.
- 첫 실제 일봉 검증의 기준 종목은 NVDA와 SPY 각 50%다. 후보는 QQQ, XLP, XLU, IEF, SHY, GLD, UUP로 고정하고 검증 종료일은 2026-11-24로 고정한다. QP-1과 같은 후보군에서 기준 종목으로 편입된 SPY를 제외해 두 실험의 입력 차이를 추적한다. 이 실행은 비교·재현 검증에 사용한다.

### 조합 성과와 수용 기준

- 기준 포트폴리오 일수익률을 `r_기준`, 후보 일수익률을 `r_후보`라 하면 세 조합의 일수익률은 각각 `r_기준`, `0.8 × r_기준`, `0.8 × r_기준 + 0.2 × r_후보`다. 가상 현금 수익률과 거래 비용은 0이다.
- QP-10의 후보 자체 성과·선정 규칙, 기간 성과, 현금 대비 급락일 차이(%p), 최소 급락일 10일과 결과 상태를 적용한다. 기준 종목과 비중, 후보, 기간과 검증 종료일, 입력 일봉 식별 정보, 급락 경계와 표본 수 및 제외 사유를 남긴다.
- 합성 입력에서 두 종목이 각각 −10%, +2%이고 비중이 각각 50%이며 후보 수익률이 +5%인 날의 세 조합 수익률은 −4%, −3.2%, −2.2%다. 현금 대비 후보 차이는 +1%p다. 기준 조합에 필요한 거래일 누락을 검증하고, 검증 기간의 가격을 바꿔도 선정 결과와 급락 경계가 바뀌지 않음을 확인한다. 기존 단일 종목 비교의 결과도 회귀 검증한다. 같은 조건으로 실제 일봉을 재조회해 입력 식별값과 비교 지표의 재현성을 확인한다.

## 종목별 방어 후보 두 개와 포트폴리오 방어 후보 한 개 비교

[QP-13](https://marcel615.atlassian.net/browse/QP-13)은 [QP-3](https://marcel615.atlassian.net/browse/QP-3)의 별도 오프라인 실험 기준이다. QP-11의 NVDA·SPY 각 50% 기준, 후보군, 가격 품질, 공통 시작일과 기간을 재사용한다. 가격은 분할조정 USD 종가이며 배당은 제외한다. 검증은 2026-11-24까지의 역사적 비교다.

### 후보 선택

- QP-10의 선정 기간 가격 품질과 누적 주가 수익률 0% 이상 조건을 충족하는 ETF를 사용한다. NVDA, SPY, NVDA·SPY 기준 포트폴리오 각각에 대해 선정 기간의 하위 10% 경계를 구한다. 각 경계 이하의 음수 수익률이 해당 기준의 급락일이다. ETF 점수는 해당 급락일의 ETF 일수익률 산술 평균이다.
- 포트폴리오 기준 ETF 한 개는 기준 포트폴리오의 급락일 점수를 최대화한다. 같은 점수이면 티커 오름차순 첫 후보를 사용한다.
- 종목별 방식은 NVDA에 배정된 ETF의 NVDA 급락일 점수와 SPY에 배정된 ETF의 SPY 급락일 점수의 합을 최대화하는 서로 다른 ETF 두 개를 사용한다. 같은 점수 합이면 NVDA 배정 티커, SPY 배정 티커 순으로 오름차순 첫 조합을 사용한다.
- 각 기준에서 급락일이 있고 적격 ETF가 두 개 이상 있어야 세 조합을 비교한다. 적격 ETF가 부족하거나 급락일이 없으면 사유를 보고한다. 선정된 티커, 각 기준의 경계와 선정 기간 급락일 수를 기록한다.

### 검증

- 검증 후보를 바꾸지 않는다. 검증은 세 조합에 필요한 모든 종목의 동일 거래일을 사용한다. 기준 종목 또는 고정된 ETF의 일봉이 빠지면 사유를 보고하고 검증 비교를 중단한다. 선정에는 통과했지만 세 조합에 쓰이지 않은 후보의 검증 결측은 이 비교의 결과를 막지 않는다.
- 모든 조합은 매 거래일 시작에 NVDA 40%, SPY 40%를 유지한다. 남은 비중은 각각 가상 현금 20%, 포트폴리오 기준 ETF 20%, 종목별 ETF 각 10%다. 현금 일수익률과 거래 비용은 0이다.
- 모든 조합의 급락일은 고정한 포트폴리오 경계와 검증 기간 기준 포트폴리오 수익률로 동일하게 정의한다. 급락일 평균 수익률, 최악 일수익률, 현금 대비 평균 수익률 차이(%p), 전체 기간 최대 낙폭과 누적 수익률을 기록한다. 급락일이 없으면 해당 급락일 지표는 산출 불가다. 10일 미만이면 표본 부족으로 표시하고 방어 효과를 판정하지 않는다.
- 예를 들어 검증 급락일에 NVDA와 SPY가 각각 −10%, +2%이고 포트폴리오 ETF 수익률이 +5%, 종목별 ETF 수익률이 각각 +5%, −1%라면 세 조합은 각 −3.2%, −2.2%, −2.8%다. 합성 예제로 이 계산, 동률, 서로 다른 ETF 배정, 누락과 기간 격리를 확인한다. 기존 QP-11 방식도 회귀 검증한다. 같은 IEX 입력을 재조회해 입력 식별값과 비교 결과를 재현한다.
