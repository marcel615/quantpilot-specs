# 분석 명세

> 프로젝트에서 합의한 분석 기준을 기록하는 선택형 양식이다. 프로젝트에서 작성·검토·승인한 뒤 공식 원본으로 설정한다.

## 목적과 적용 범위

- [분석이 답해야 할 질문, 결과 사용처, 적용 범위]

## 입력 데이터

- [데이터 출처, 대상과 기간, 기준 시점 또는 갱신 주기]
- [결측·중복·이상값 등 결과에 영향을 주는 입력의 처리 기준]

## 처리와 계산 규칙

- [포함·제외 조건, 변환·집계·비교 방법, 결과에 영향을 주는 가정]

## 산출물과 지표

- [산출물의 용도, 지표의 정의·단위·기준일, 필요한 경우 갱신 조건]
- [연동 인터페이스가 있는 경우 공식 API·데이터 계약 링크]

## 수용 기준

- [대표 입력과 기대 결과, 허용 오차, 검증할 경계 조건]

## 미결 사항

- [확정이 필요한 규칙과 결정에 영향을 받는 범위]
